做 labelreplay，验证合成文档批处理的标签传播是否依照隔离政策。每个节点是文件、只保留长度的信息摘要或给特定组阅读的报告。处理节点可同时依赖数据来源、控制条件和回滚前的输出版本；对直接数据和控制标签使用不同规则。一个带已批准概要函数的节点只有在输出抽象值于所有允许的源输入一致时才能去掉相应标签。合成有限域中每个源取 2–4 种符号，规则可把值与同一源的另一版本联立，使两个分支各自看似可达但不能同时出现。冻结的政策可在某个版本窗口撤销白名单，旧报告复核用当时版本。
实现 prove CASE，求给定保护组能看到的所有报告摘要族是否在保护标签对应的源变量变化时保持一致，同时固定其他源变量，返回最短敏感作用链与两组满足约束的合成赋值，或给可重放的安全证明。做 amend，从 16 个已许可的屏蔽控制信号、替换摘要算子、禁止输出的动作中选最少损失最小可行计划，同时保留指定观察点的业务信息区分能力。验收时会篡改一项见证、一个相互依赖分支的可达性以及替代计划的决胜顺序。给两项手算实例和小有限域全枚举。数据只用虚构符号。
从空仓库实现，使用 Windows 普通 CPU 和 Python 3.12 标准库，全部离线。交付 UTF-8 JSON CLI、明确的输入格式、README、合成夹具及 unittest。
